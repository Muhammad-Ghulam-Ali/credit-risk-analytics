# Processed Data

This folder holds cleaned/processed datasets generated by the notebooks in this project.
Files here are excluded from version control (`.gitignore`, `*.csv`) since they are
derived outputs, not source data.

To regenerate: run `notebooks/02_outlier_treatment.ipynb`, which exports the cleaned
`application` table (outlier flags, DAYS_EMPLOYED anomaly handling applied) to
`clean_data.csv` in this folder.
